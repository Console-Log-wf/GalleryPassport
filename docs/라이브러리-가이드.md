## 0. 먼저, 우리 프로젝트가 뭐였죠? (30초 요약)

**Gallery Passport** = 직접 가지 않아도 세계 유명 박물관의 작품을 보고, **여권에 스탬프**를 모으는 온라인 갤러리.

```
[홈: 3D 지구본] → 나라/박물관 클릭 → [전시관: 복도/액자 벽 + 미니맵]
                                          ↓ 작품 클릭
                                   [작품 상세 모달 + 도슨트 설명]
                                          ↓
              [여권(플로팅): 스탬프 · 즐겨찾기(우표) · 관람 진행률]
```

**왜 만들었나?** 국립중앙박물관은 외국인 관람객이 많아 입장이 제한되고, 한국인도 여러 나라를 직접 가기 어렵다 → 전 세계 사람이 온라인으로 즐기는 갤러리.

**핵심 화면 4개**

| 화면 | 하는 일 |
|---|---|
| 입구(홈) | 지구본 + 나라 국기/박물관 → 해당 갤러리로 이동 |
| 전시관 | 복도(또는 액자 벽)를 걸으며 작품 감상, 미니맵으로 현재 위치 확인 |
| 작품 상세 모달 | 큰 이미지, 작가/작품 설명, 도슨트, 이전/다음 작품 |
| 내 여권 | 스탬프(다 돌아보면 찍힘), 즐겨찾기(우표 컨셉), 진행률 |

## 1. 라이브러리란? (한 줄 설명)

> 직접 만들면 오래 걸리는 기능을 **남이 만들어 둔 코드**로 가져다 쓰는 것.
> 예) 3D 지구본을 처음부터 만들면 몇 주 걸리지만, `react-globe.gl`을 설치하면 몇 줄로 끝난다.

**중요:** 이 프로젝트의 주인공은 **React 기본 기능**입니다. 수업 과제이므로 상태 관리 같은 건 외부 라이브러리 없이 React 내장 기능(`useReducer`, Context 등)으로 합니다.

## 2. ⭐ 핵심 라이브러리 (발표에 꼭 넣을 것)

| 분류 | 이름 | 한 줄 설명 | 우리가 쓰는 곳 |
|---|---|---|---|
| 개발 환경 | **Vite** | React 프로젝트를 빠르게 만들고 실행해 주는 도구 | 프로젝트 세팅 |
| UI | **React** | 화면을 컴포넌트(레고 블록)로 만드는 라이브러리 | 전체 |
| 페이지 이동 | **react-router-dom** | URL에 따라 다른 화면을 보여줌 | `/rooms/:roomId`, `/artworks/:id` (모달도 URL과 연결) |
| 3D 지구본 | **react-globe.gl** | 돌아가는 3D 지구본과 마커를 쉽게 만듦 | 홈 화면 지구본, 나라 클릭 → 갤러리 이동 |
| 애니메이션 | **framer-motion** | 부드러운 움직임/드래그를 몇 줄로 구현 | 모달 열림, 스탬프 찍히는 효과, 떠다니는 여권 |
| 스타일링 | **Tailwind CSS** | 클래스 이름만으로 디자인 | 나라별 벽 배경, 액자, 여권/우표 디자인 |
| 아이콘 | **lucide-react** | 깔끔한 아이콘 모음 | 이동 버튼, 즐겨찾기, 닫기 |

## 3. React 기본 기능 (설치 불필요! 수업 포인트)

구상안의 "React가 돋보이는 지점"과 연결됩니다.

| React 기능 | 우리 프로젝트에서 |
|---|---|
| **컴포넌트 + props** | 작품 카드, 상세 모달, 갤러리 패널을 재사용 부품으로 설계 |
| **useReducer + Context** | 관람 위치 / 선택 작품 / 즐겨찾기 / 스탬프를 전역 상태로 관리 |
| **useEffect** | 방향키 이벤트 등록·해제(cleanup), 작품 데이터 불러오기 |
| **useRef** | 복도 스크롤 위치 제어 |
| **useMemo** | 필터 결과, 관람 진행률(본 작품 수 / 전체) 계산 |
| **createPortal** | 모달·플로팅 여권을 화면 맨 위에 띄우기 |

## 4. 기능별 보조 라이브러리 (필요할 때 골라 쓰기)

### 🌍 지구본 · 국기
- `flag-icons` / `country-flag-icons` — 나라 국기 이미지
- `world-atlas` + `topojson-client` — 나라 경계 데이터
- (대안) `cobe` — 더 가벼운 지구본. 다만 클릭 상호작용은 react-globe.gl이 쉬움

### 🖼️ 복도 갤러리 (난이도 선택)
| 방식 | 난이도 | 사용 도구 |
|---|---|---|
| 액자가 걸린 벽 (가로 스크롤) | 하 | 순수 CSS + `useRef` |
| 원근감 있는 복도 (2.5D) | 중 | CSS `perspective` + framer-motion → **추천** |
| 진짜 3D 복도 | 상 | `three` + `@react-three/fiber` + `@react-three/drei` (일정 부담 큼) |

- 방향키 이동: `useEffect`로 직접 구현 또는 `react-hotkeys-hook`
- 드래그/스와이프: `@use-gesture/react`
- 미니맵: SVG/CSS로 직접 그리기

### 🛂 여권 기능
- **저장 유지**: `localStorage` (새로고침해도 스탬프/즐겨찾기 유지). 라이브러리 없이 커스텀 훅으로 충분
- **플로팅(떠다니는) 여권**: framer-motion `drag` 또는 `react-draggable`
- **완주 연출**: `canvas-confetti` (다 돌아보면 스탬프 + 폭죽)
- **여권 이미지로 저장**: `html-to-image` (PNG 다운로드 → 발표에서 눈에 띄는 기능)
- **접근성 좋은 모달**: `@radix-ui/react-dialog` (직접 만들어도 OK)

### 🎧 도슨트
- 브라우저 내장 **Web Speech API**(`speechSynthesis`)로 설명 읽어주기 — 설치 필요 없음

### 📦 데이터 · 이미지
- 작품 정보는 처음엔 **JSON 파일**로 관리 → `fetch`로 불러오기
- 필요하면 `msw` 또는 `json-server`로 가짜 API 만들기
- 이미지 지연 로딩: `loading="lazy"` 속성이면 충분
- 다국어(한/영): `react-i18next` (선택)
- 이미지 출처 후보: Wikimedia Commons, Met Museum Open Access API, Art Institute of Chicago API

### 🧰 개발·협업 도구
- **ESLint + Prettier**: 코드 스타일 통일
- **Git/GitHub**: 페이지별 브랜치 (입구 / 전시관 / 마이페이지)
- **Vercel / Netlify / GitHub Pages**: 배포
- **Figma**: 화면 설계 + 발표용 "예상 output image"

## 5. ⚠️ 주의할 점

1. **저작권**
   구상안의 MoMA 추천작 중 달리·워홀·피카소·마티스·몬드리안·와이어스·오펜하임 작품은 저작권이 남아 있을 가능성이 큽니다.
   → 공개 도메인 작품(고흐, 모네, 루브르의 고전 작품 등)을 우선 사용하고, 그 외는 **출처 표기 + 학습용** 명시.
2. **범위 조절**
   지구본과 복도를 둘 다 3D로 만들면 위험합니다.
   → 지구본은 react-globe.gl로 해결, 복도는 **2.5D(CSS)로 시작** → 시간 남으면 3D.
3. **백엔드는 일단 없음**
   `localStorage`만으로 모든 기능이 가능합니다. 로그인/계정별 저장이 필요해지면 그때 Firebase 등 검토.
