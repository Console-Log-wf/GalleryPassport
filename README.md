# GalleryPassport

세계 유명 작품을 나라별 가상 갤러리로 전시하는 웹 서비스 (2026 웹프레임워크1 프로젝트).

## 실행
```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # 배포용 빌드 확인
```

## 스택
React 18 · Vite · React Router · Tailwind CSS + daisyUI · framer-motion · react-globe.gl · room-gallery · canvas-confetti · html-to-image

> `room-gallery`가 React 18까지만 지원해서 React는 18로 고정했습니다. 19로 올리지 마세요.
